# Contributing to DroidModKit

Thanks for your interest in improving DroidModKit.

## Getting started

1. Fork the repository.
2. Create a feature branch.
3. Keep changes focused and document user-visible behavior.
4. Run the application and verify the affected workflows before opening a pull request.

## Project principles

- Keep APK inspection read-only by default.
- Do not add payment, license, or access-control bypass functionality.
- Do not execute APK contents during inspection.
- Clearly document limitations and supported Android/APK formats.
- Only test against APKs you own or are authorized to inspect.

## Pull requests

Include a concise summary, testing performed, and screenshots for UI changes where useful.
