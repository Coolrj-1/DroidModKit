# Changelog

## 0.2.0 - APK inspection workbench

- Add archive-path filtering in the desktop interface.
- Add file extension counts and APK inventory metadata.
- Detect signature-related files, duplicate paths, suspicious paths, encrypted entries, and high compression-ratio entries.
- Expand JSON inspection reports and clarify heuristic limitations.
- Add automated unit tests for valid APKs, invalid ZIP archives, and invalid file types.
- Update project documentation and safety notes.

## 0.1.0 - Initial public release

- Add read-only APK ZIP inventory GUI.
- Add SHA-256 calculation and JSON report export.
- Document scope, limitations, and roadmap.
